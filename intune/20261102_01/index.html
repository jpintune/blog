Intune のサポート対象 OS とライフサイクルの考え方 (Windows / Apple / Android)

Last Update: 2026-11-02 feedback 共有

みなさま、こんにちは。Intune サポート チームです。

Intune で管理するデバイスの OS は、Windows、iOS/iPadOS、macOS、Android と、それぞれ新しいバージョンが定期的にリリースされます。そのため、「この OS バージョンは Intune でサポートされているのか」「新しい OS がリリースされたら、すぐに Intune で管理できるのか」といったご質問をいただくことがよくあります。

本記事では、Intune で管理する主要な種類のデバイス (Windows、Apple、Android) について、Intune におけるサポート ライフサイクルの一般的な考え方と、最新の情報を確認できる場所をご紹介します。なお、Intune では新しい OS バージョンについて、主要な OS は基本的にゼロデイ サポート (OS のリリース日から利用できる状態) を目指して対応を進めています。

最新の情報を確認できる場所

サポート対象の OS は定期的に更新されるため、本記事の内容だけでなく、必ず最新の公開情報をご確認ください。次のページが基本となります。

サポート対象の OS バージョン

  • Intune でサポートされるオペレーティング システムとブラウザー (日本語版)
    https://learn.microsoft.com/ja-jp/intune/fundamentals/ref-supported-platforms#intune-supported-operating-systems

  • Supported operating systems and browsers in Intune (英語版)
    https://learn.microsoft.com/en-us/intune/fundamentals/ref-supported-platforms#intune-supported-operating-systems

💡 NOTE
日本語版は英語版の翻訳であるため、更新が反映されるまで時間差が生じる場合があります。最新の情報を確認したい場合は、英語版もあわせてご参照ください。

サポートの変更に関する案内

新しいバージョンのサポート開始や、古いバージョンのサポート終了・変更は、下記の公開情報にて事前に通知を行うことがあります。

  • Microsoft Intune の新機能 / 重要な通知
    https://learn.microsoft.com/ja-jp/intune/whats-new/#notices

加えてメッセージ センターにも、事前に通知する場合があります。メッセージ センターの通知内容については、Intune 管理センターの [テナント管理] - [テナントの状態] にある [サービス正常性とメッセージ センター] からも確認できます。

  • Intune のテナントの状態ページでテナントの詳細を表示する / [サービス正常性とメッセージ センター] タブ
    https://learn.microsoft.com/ja-jp/intune/governance/tenant-status#service-health-and-message-center-tab

また、開発部門が公開している下記のブログにおいても、通知が行われることがあるため、こちらも併せてご確認ください。

  • Intune Customer Success (Tech Community ブログ)
    https://techcommunity.microsoft.com/category/microsoftintune/blog/intunecustomersuccess

Windows

Windows については、上記のサポート対象 OS のページに「Windows 11 Home、S、Pro、Pro Education、Education、Enterprise、IoT Enterprise エディション」や「Windows 10 LTSC 2019/2021 および Windows 11 LTSC 2024 (Enterprise および IoT Enterprise エディション)」が記載されており、基本的に Windows のサポート期間内の OS であれば Intune からも問題なく管理していただけます。

Windows 自体のサポート期間 (サービス ライフサイクル) は、次の Windows リリース情報で確認できます。

  • Windows 11 リリース情報
    https://learn.microsoft.com/ja-jp/windows/release-health/windows11-release-information

Apple (iOS / iPadOS / macOS)

Apple デバイスについては、「最新の 3 つのメジャー バージョン」を目安にサポートされます。毎年秋ごろに新しいバージョンが Apple よりリリースされると、サポート対象の範囲も 1 つ新しいバージョンへ移動していく形になります。

なお、上記の公開情報では、「サポートされるバージョン」と「登録が許可されるバージョン」が次のように区別されています。

区分 内容
サポートされるバージョン 最新の 3 つの OS バージョンを実行しているデバイスです。適用可能なすべての Intune の機能を登録して利用でき、新しい機能もこれらのデバイスで動作します。
登録が許可されるバージョン サポートされるバージョンより古い OS バージョンのデバイスです。登録して Intune の機能を利用することはできますが、期待どおりに動作する保証はありません。

💡 NOTE
「登録が許可されるバージョン」は、ユーザー アフィニティのないデバイス (ADE や Apple Configurator で登録するデバイス) に対して案内されています。登録の種類ごとの具体的な対象バージョンについては、必ず上記の公開情報をご確認ください。

Android

Android では、機種ごとに利用可能なバージョンの範囲も大きく異なることから、現在は Windows や Apple のように「最新の○バージョン」といった厳密なサポート ライフサイクルが定められているわけではありません。代わりに、必要に応じて、サポート対象とする最小の Android バージョンが引き上げられていきます。

また、Android は登録方法 (ユーザー ベース / ユーザーレス等) によってサポートされるバージョンが異なります。具体的なバージョンは、上記の公開情報の「Android」の項目で登録方法ごとに案内されていますので、ご利用の登録方法に該当する部分をご確認ください。

ユーザー ベースの管理方法で Android 10 以降が対象になった際の変更は、公開情報上の通知だけではなく、次の Tech Community ブログやメッセージ センターでも事前に案内されました。

  • Intune moving to support Android 10 and later for user-based management methods in October 2024
    https://techcommunity.microsoft.com/blog/intunecustomersuccess/intune-moving-to-support-android-10-and-later-for-user-based-management-methods-/4055307

今後も同様に、Android の新しいバージョンのリリース等に伴って、サポート対象の最小バージョンが引き上げられる場合があります。Android を運用されている場合は、上記の Intune Customer Success ブログやメッセージ センターで、事前の案内を確認していただくことをお勧めします。

注意点

ここまでご紹介したのは、あくまでも Intune 観点でのサポート ポリシー です。

実環境でデバイスを運用する際には、Intune だけでなく、デバイス上で利用する様々なアプリ等の要件も踏まえて、適切な OS バージョンで運用していただく必要があります。たとえば Office 関連のアプリでは、Intune とは別に次のようなシステム要件が定められており、ブログの執筆時点では iOS や Android については Intune の要件よりも厳しい条件が設けられています。

  • ビジネス、教育機関、政府機関向けの Microsoft 365 のシステム要件
    https://support.microsoft.com/ja-jp/office/system-requirements/system-requirements-for-microsoft-365-for-business-education-and-government-use
OS Microsoft 365 アプリのシステム要件 (概要)
Windows Windows 11、Windows Server 2025、または Windows Server 2022
macOS 最新の 3 つのバージョンのうちの 1 つ
Android 直近 4 つのメジャー バージョン
iOS 最新バージョン 2 つ

実際にお問い合わせの中でも、調査を進めたところ、問題が発生していた iOS のバージョンは Intune 観点では問題ないものの、Office アプリの観点からはサポートされないバージョンであったといったケースも、よくあります。

OS のバージョンを選定したり、アップグレードの計画を立てたりする際には、Intune のサポート対象に加えて、利用するアプリの要件も確認したうえで進めていただければと思います。

まとめ

  • Intune のサポート対象 OS は、公開情報 (「Intune でサポートされるオペレーティング システムとブラウザー」) で確認できます。
  • Windows は OS 自体のサポート期間、Apple は最新の 3 つのバージョンが目安となり、Android は登録方法ごとにサポート対象の最小バージョンが定められ、必要に応じて引き上げられていきます。
  • 変更の案内は、メッセージ センターや Intune Customer Success ブログで事前に確認できます。
  • Intune のサポートに加えて、デバイス上で利用するアプリ (Microsoft 365 アプリ等) の要件も確認してください。

本記事が、デバイスの OS バージョンを検討する際の参考になりましたら幸いです。
